分域代理

让指定的网站走本地 Clash，其余保持直连。改动立刻生效。

代理

Clash Verge 的 mixed-port（默认 7897）同时吃 HTTP 和 SOCKS5，选哪个都行。 不确定端口就打开 Clash → 设置 → 端口，看「混合端口」那个数。

哪些站走代理

一行一条，# 开头是注释。只写域名就按「后缀」算（google.com 会覆盖 www.google.com、mail.google.com 等所有子域）。
也认 Clash 原生写法：DOMAIN,x.com（只这一个）、DOMAIN-SUFFIX,x.com、 DOMAIN-KEYWORD,google、IP-CIDR,10.0.0.0/8。
规则匹配的是域名，不是 IP —— 所以 CDN 上的站点（很多静态资源在别的域）可能需要把那些域也加进来， 否则主页面走了代理、子资源还在直连。
